# reflex-machine

A fast-paced, browser-based reaction game inspired by the classic "Bop-It" toy. The screen rapidly flashes a random instruction (e.g., "Click", "Double Click", "Press Spacebar", "Press Enter"), and the player has exactly two seconds to perform the correct action before the timer runs out.

## Tech Stack
This project is built using:
- **Framework**: [Next.js](https://nextjs.org) (App Router, TypeScript)
- **Styling**: Vanilla CSS

## Getting Started

First, install the dependencies:

```bash
npm install
```

Second, run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

You can start editing the page by modifying `src/app/page.tsx`. The page auto-updates as you edit the file.
